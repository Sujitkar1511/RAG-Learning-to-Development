# Day 4 — File Handling

This day focuses on learning the fundamentals of **File Handling in Python**.

## 📚 Topics Covered

### 1. File Handling Basics

* File Handling
* Opening a file using `open()`
* Closing a file using `close()`
* Using `with open()`

### 2. File Modes

| Mode | Purpose               |
| ---- | --------------------- |
| `r`  | Read                  |
| `w`  | Write / Overwrite     |
| `a`  | Append                |
| `x`  | Create                |
| `r+` | Read + Write          |
| `w+` | Write + Read          |
| `a+` | Append + Read         |
| `x+` | Create + Read + Write |

### 3. Reading Files

* `read()`
* `readline()`
* `readlines()`

### 4. Writing Files

* `write()`
* `writelines()`

### 5. File Cursor

* Understanding the file cursor
* `seek()`
* `seek(0)`

### 6. Text Files

Working with `.txt` files:

* Creating text files
* Reading text files
* Writing text files
* Appending text
* Clearing file content
